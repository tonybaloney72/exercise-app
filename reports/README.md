# Catalog audit reports (Phase 0)

Generated by:

```bash
npm run audit:catalog
```

Optional link checks (slow):

```bash
npm run audit:catalog -- --check-links
```

## Outputs

| File | Purpose |
|------|---------|
| `catalog-audit.json` | Full inventory, per-exercise flags, category totals |
| `catalog-audit.csv` | Flagged rows only — open in a spreadsheet for Phase 1 burn-down |

Re-run after catalog edits to track progress. JSON/CSV are gitignored; this README is committed.
